# PepBridge-Bench v0.2 协议

2026-10-15，Asia/Shanghai。协议依据[更新对话第 3–5 轮](../docs/PUBLICATION_SCOPE.md)，取代旧 T1/T2/T3 作为后续正式结果的组织方式。机器配置以 `configs/bench_v02.json` 为准；数据准备、训练、生成和评价分别保留状态。本文定义待执行实验，旧结果继续保存在原目录。

核心问题是：在相同分子信息、监督和预算下，连接器能否保留实际预测精度，并让语言模型获得强预测流水线难以替代的迁移或知识组合收益？A 类检验实用价值，B 类检验语言模型的额外价值，C 类检验信息利用及其归因。

2026-10-15 本轮执行修订：按用户最新要求，A1、B1 的单面板预测器基线在各自划分和输入锁定后独立训练，A2 的尺度核查及 B2 证据准备不再作为它们开跑的前提。每个面板保存实际数据、同源比对、分组审计和候选目录的物理指纹；训练前重新计算划分隔离。外部数据覆盖未齐时使用 `frozen_restricted_scope`，结果保留缺失范围，不能声称完整外部零暴露。统一多任务连接器的正式主张仍遵守下文的统一 checkpoint 合同。

本轮预算在训练前保存于 `results/bench_v02/panel_baselines_20261015/preregistered_protocol.json`：随机基线使用 17/42/2026 三种子、30 epochs、batch 64、AdamW、学习率 3e-4、weight decay 0.01，不提前停止；按验证集最早最佳 MAE（A1）或类别宏平均 MRR（B1）选 checkpoint。确定性的组成/化学特征 ridge、kNN 只在预登记参数网格内用验证集选择。底座冻结，不复用旧任务训练权重。A1 靶点全序列采用连续、不重叠的 1022 残基分块并覆盖所有残基；分块间上下文断开明确记录。

## 1. 六个主面板与文字解释交叉评价

| 面板 | 固定问题 | 主数据与独立单位 | 主指标 |
|---|---|---|---|

| A2 | RT 数值和跨条件标注效率 | PXD005573 源域；PXD064311 指定目标条件；peptidoform/母体/实验组 | 分条件 MAE、Spearman、32/128/512/2048 标签预算曲线 |
| B1 | 未见功能类别的描述对接 | ELM 类别及经序列核验的局部实例；类别及独立来源区段 | 未见类 Macro-MRR、Recall@1/3；已见类另报 |

| C1 | 答案是否依赖当前分子消息 | 复用 A/B 锁定测试对象与 checkpoint | 正确−关闭 U、正确−匹配错配 D、相对恒定消息系统收益、交换一致性 |

## 2. 数据证据与 phase 0 锁定

每个数据版本记录下载 URL、时间、文件 SHA-256、来源论文/快照版本、sheet/行、原始值、清洗决策和排除原因。论文报告规模、当前公开快照行数、合格记录数、独立组数、最终划分保留率分别报告。实际数量及尚待解决的问题引用三个持续更新的审计报告：[A1 数据审计](bench_v02_affinity.md)、[A2 数据审计](bench_v02_rt.md)、[B1 数据审计](bench_v02_elm.md)。协议不将下载成功等同于可训练。

Phase 0 的执行顺序：

1. 锁定 Kliche、PEPBI、原始实验结构及其论文、实验、母体区段和变体系列；保存外部排除清单。
2. 审计 PPIKB 各表对应关系、数值和化学状态冲突；审计 RT 来源、条件、peptidoform 身份；核验 ELM 区段序列和类别描述。
3. 先固定 ELM 类别 train/validation/test，再从所有监督来源排除验证/测试类别实例及其同源答案。验证类只供选择协议，不回流训练。
4. 跨 PPIKB、ELM、Benz、RT、外部论文进行重复实验、相同序列、母体重叠区段、变体系列与适当家族的全局审计；保存具体相似性规则和连通组。短肽规则随长度/基序特点定义。
5. 冻结逐样本 split、group_id、双侧靶点相似性和来源排除清单；记录冲突处理、跨侧丢弃记录和保留率。默认比例 70/15/15 服从组间隔离。
6. 机器预检与人工证据审查通过后，才开放联合训练。B2 证据卡登记与经双人核验的问答案例分别计数。

“未进入本项目监督训练”是可审计的暴露范围；底座预训练暴露另行披露。历史 Kliche D2 训练过的模型单列 exploratory，正式外部零暴露结果从 phase 0 新锁定的数据重新训练。

## 3. A1：亲和力与真实肽对

主标签仅为研究论文来源的 KD，转换为 `pKD = −log10(KD / M)`。Ki、IC50、EC50 分开保留；上下限和 n.d./n.b. 保留原定义。精确 KD 回归与删失记录评价分表，范围标签不伪装成点值。

首版使用 5–50 aa、标准残基、线性且化学状态明确的记录。修饰、末端状态、靶点构建体和条件缺失均有显式字段；跨表冲突隔离后回查证据。广覆盖候选保留缺失标记，严格同条件配对需原文明确支持，不能用两个缺失值推定相同条件。

输入包括实际肽/状态、靶点或实际构建体序列、允许条件和问题。未见靶点面板必须提供真实可用序列，opaque ID 或 onehot 无法承担该测试。所有方法获得相同信息。

划分分别评估新肽家族—已见靶点、以及新肽家族—新靶点家族；随机记录划分仅作补充。双侧相似性隔离后的保留率和家族分布必须公开。

主表报告 pKD MAE；Spearman 在有足够可排序、非恒定测量的靶点—可比条件组内计算，再宏平均，并列出有效组数。方向只在原始误差/界限和预定最小变化阈值能支持结论时定义，未知、小变化及等效分别保存。同一肽对两个顺序共享 group_id，报告 accuracy、balanced accuracy、混淆矩阵、预测反转率与交换后对应标签的正确率。Kliche、PEPBI 及原始实验结构用于锁定外部评价，记录其序列一致性和跨库排除覆盖。

## 4. A2：RT 和少样本适配

源域固定为 PXD005573，目标域为 PXD064311 的预定条件。下载所得文件必须证明来源与目标表字段及原论文实验对应，RT 单位和条件分别核验。相同序列不同 peptidoform 保留状态；关联观测按组隔离。

源域内测试未见肽/来源组。跨条件设两个面板：允许源训练见过部分目标肽；以及目标测试肽同时从源训练隔离。分别报告。

目标标注预算为 32、128、512、2048，采用固定、嵌套、各方法共享的目标标签子集和独立固定测试集。每个预算从同一个源 checkpoint 开始，不能从较小预算适配模型继续累计训练。目标校准、tune/validation、早停、超参选择使用的全部标签计入该预算；每条标签角色和唯一 ID 可核查。预算不足、目标条件未核验时标 pending，不自动用替代数据填满。

MAE 和 Spearman 按条件分别报告，公开误差分布和完整预算曲线。DeepLC 2026 论文复现版本作为明确固定版本的参考；当前公开预训练系统另列实际使用面板，记录已知训练来源及测试暴露状态。版本、权重、预训练来源核验见 A2 审计。

## 5. B1：未见类别描述

每类至少 10 个独立来源区段为起始资格门槛，独立性经过母体重叠和家族审计后计算。以类别划分 train/validation/test；当前快照与 2024 论文归档版本分开记录。可用类数、实际未见类数及其分布由审计确定。

主候选范围采用已核实的人类与模型真核物种，human-only 产物保留作范围敏感性。主范围使用版本化的70/15/15类别hash规则，随后执行母体、序列、来源隔离和资格筛选，报告最终实际比例。范围与hash规则依据协议和数据覆盖确定，未使用模型成绩选取。

主面板对所有系统提供相同候选功能描述，去掉正则表达式、直接序列答案和实例泄漏；描述仍需人工审查。完整规则面板另报并加入规则匹配。ELM 输入标成蛋白质局部功能区段，局部注释保持其原始生物学范围。

保存候选集合与顺序、每条完整排名、已知阳性及未知关系。先对同一类别实例求平均，再对类别宏平均 MRR 和 Recall@1/3；同时报告样本平均、已见类结果和有效分母。未注释关系为未知；无完整负证据时不计算实验阴性意义上的 AUROC。

## 6. B2：证据支撑的组合

每例保存分子输入、作用对象、允许背景、问题、隐藏原子事实、证据定位、允许推断和禁止外推范围。背景去除当前分子的实测答案及能直接揭示答案的名称。关系—问题组合整体留出；改写、交换和同例多问题归于同一独立案例。

主面板显式提供类级背景，隐式背景版本单列。只有真实可关联的测量才组成多性质案例；受控逻辑题单列，不与新生物学实验证据合并。每例经两位评审核对来源、关联和答案后进入正式集合。

必须同时比较候选接口、BASE-03 强预测器→完整结构化事实→同一 LLM，以及真实分子事实→同一 LLM 的诊断上限；简单规则可完整解决的题同时加入程序基线。预测器提供数值、后验、局部打分和不确定性，不能只提供粗标签。

联合正确率要求分子判断与背景结论均正确。另报必要事实覆盖、矛盾、未支持推断，以及真实事实输入下的条件正确率。上限输入只用于诊断，不进入正式模型训练或模型选择。

## 7. C1：通信内容干预

冻结同一个 checkpoint、问题、靶点、条件和评分接口，运行正确消息、关闭消息、匹配错配及 A/B 交换。另行训练等预算恒定消息系统作为参数/静态先验对照。

匹配错配供体来自同一锁定测试面板，要求相同靶点/构建体和可比条件、长度/状态分布接近、独立分子组；匹配规则与供体表在看预测前锁定。不足时公开覆盖和分母，不放宽成跨靶点随机供体。正确−关闭定义 U；正确−错配定义 D；回归使用负 MAE 等越大越好的 S 计算差值。共同覆盖子集与全面板分别报告。

交换分子同步交换参考答案；错配改变分子身份时，受体标签下降用于检测消息依赖，不要求模型神奇恢复原分子的答案。有真实供体标签时另报对供体事实的符合程度。正确消息首先应胜过关闭和独立恒定系统；巨大错配损失本身不构成通信收益，也不作为训练最大化目标。供体次数、问法数、交换次数不增加独立样本量。

## 8. C2：表示、干预和局部证据

三处探针依次读取原始 ESM 残基表示、连接器输出、LLM 接收后答案生成前的状态。相同训练记录、分组、池化规则、压缩维度、参数容量、调参预算及控制任务；维度压缩和标准化仅由训练集拟合。加入长度、组成、靶点和条件基线，计算超出简单基线的信息。禁止 teacher-forcing 正确答案后的状态。

表示交换成分在 train/validation 确定后锁定，测试集只执行。报告目标事实干预成功率及无关事实保留率。局部充分性和移除后的完整性检验加入同长度随机区域对照；优先采用真实肽对/实验变体替换，直接遮蔽的分布外风险随结果说明。

局部金标准分两级：序列匹配的原始实验复合物支持“结构接触一致性”；直接实测变体/区域支持“功能变化一致性”。分别报告有效区域覆盖、残基排序或 Precision@K、测试残基范围和未知位置。PEPBI 建模副本不作为独立实验结构，结构接触、功能热点及完整生物学机制保持不同证据等级。注意力权重只作描述。

## 9. C3：文字解释按原子事实评分

每个可核查原子事实标为 supported、contradicted、unsupported/unknown，并保存证据位置。缺少证据与存在反证分别统计。

| 指标 | 分母与定义 |
|---|---|
| 支持精确率 | 有证据支持的输出原子事实 / 全部可核查输出原子事实 |
| 必要事实覆盖 | 正确覆盖的必要事实 / 预定必要事实 |
| 矛盾率 | 与实验或给定背景冲突的输出事实 / 全部可核查输出事实 |
| 未支持推断率 | 以确定结论表达但证据不足的推断 / 全部可核查输出事实 |

空回答必要事实覆盖为 0，支持精确率记未定义并报告空答率；格式无效与缺字段计入失败。200 个独立案例是规划目标，正式数量由可核验案例决定；生成改写不补独立样本数。两位评审独立、盲法标注并仲裁，保存一致性、版本及来源；自动评分只作辅助。

## 10. 同信息基线、候选设计和公开系统

基线采用 BASE 前缀，与 B1/B2 测试面板区分。

| ID | 必跑实现族 | 作用 |
|---|---|---|
| BASE-00 | 近邻、理化特征、仅在训练集建模的基序模型 | 简单规律下限 |
| BASE-01 | ESM 残基注意力池化＋充分调优的条件化/多任务分类回归头 | 强专项预测器 |
| BASE-02 | ESM＋功能文字编码器的判别模型 | ProtNote-style 开放标签控制 |
| BASE-03 | 最强预测器→完整结构化结果→同一冻结 LLM | 语言组合强流水线 |
| BASE-04 | 残基表示→普通输入投影→同一冻结 LLM | 常规输入接口 |
| BASE-05 | Q-Former 输入连接 | ProtT3-style 控制 |
| BASE-06 | 普通门控内部跨注意力 | 已有内部读取控制 |

BASE-01/02/03 获得相同来源层、残基分辨率、靶点/条件/描述/背景及允许的配对差分特征。BASE-03 在训练集内生成训练所需预测特征，避免把对自身标签过拟合的结果当部署输入；流水线训练和调参总成本完整计入。style 实现与原论文完整复现分别登记。

M0 为旧逐残基 MLP 接口基线。M1 是侧记忆读取，M2 增加独立层投影和问题相关读取，M3 增加可对齐肽对的共同背景/差异通道，M4 增加配对交换一致性与事实字段计权。这些是候选设计，尚无新版实现训练结果。M1 和 BASE-06 发生同构时共用结果，不人为重复命名为两个新方法。

候选起点为 ESM 15/30 层分别 640→128 投影，四头跨注意力读取，Qwen 第 14 块后写回，单接收位置，两端冻结。M3 仅在等长、位置对应可靠的肽对上启用；普通双分子表示保留。相同差分输入也交给专项预测器与普通 MLP 控制。M4 的事实/解释/一致性权重为验证集候选，统一字段归一化；不把门控、低秩或相减单独作为原创。

公开系统另表登记 OPUS-PLLM、ProtT3、ProtNote、DeepLC、PepInter 的固定代码/权重、额外训练/结构信息、暴露范围和实际复现状态。PepInter 原始数据可用性按最新官方发布核验，不能仅沿用旧 README 的待发布描述。未复现项目记原因与状态，不按零分处理。

## 11. 训练、预算、输出与统计合同

固定起点 ESM2-150M＋Qwen2.5-1.5B-Instruct，两端冻结；seeds 为 17、42、2026。Phase 1 使用严格隔离后的 ELM/Benz 训练部分做基础对齐；phase 2 在 KD、RT、功能训练部分任务均衡采样，字段和任务损失归一化；phase 3 按上述预算复制同一源 checkpoint 做适配；phase 4 锁定评价。

每方法每 seed 产生一个多任务源 checkpoint；只能用预先锁定的多任务验证规则选择它。每任务独立挑最佳 checkpoint 再拼表不构成统一模型。少样本适配版本单独标注，并保存其源 checkpoint 指纹。阶段总步数、每任务生物样本呈现、batch/累积、超参候选和试验数、选点规则、数据与代码哈希在训练前写入配置；配置缺项时不启动正式训练。BF16、AdamW、有效 batch 约 32 是起始工程设置，具体值由固定配置记录。

同信息控制表匹配训练证据、样本呈现和预定调参预算；同时报告真实时间/显存/算量，不把参数接近写成计算成本相同。RT 大数据不因记录多自动获得更大损失权重。数值变换、标准化、特征压缩仅训练集拟合。

生成与读出两通道分别输出逐样本结果。生成通道保留原始自回归文本、解码参数、JSON/数值解析、单位、缺失和错误；禁止事后人工修正再算主成绩。解析有效率及全样本任务成功率与有效答案 MAE 同时报，失败不得静默从分母删除。答案前表示接等规格预测头的结果标 readout；固定单 token 别名候选排名标 legacy_alias_ranking，不进入生成主表。
