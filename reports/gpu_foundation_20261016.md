# A1 已知靶点：GPU 基础测试结果

固定 train 2,062 / validation 147 / test 152；四种连接器各独立训练三轮、seed 17、batch 4，按完整验证集答案 token NLL 选择检查点。五个完整基准进程均正常退出，所有输入快照、检查点、预测和指标通过独立复算。

| 通道 / 方法 | 测试数 | JSON 有效数 | 有效答案 MAE（pKD） |
|---|---:|---:|---:|
| 连接器：input_mlp | 152 | 152 | 1.99624 |
| 连接器：qformer_style | 152 | 152 | 1.44267 |
| 连接器：internal_cross_attention | 152 | 152 | 2.16133 |
| 连接器：constant | 152 | 152 | 1.96561 |
| 冻结预测器原始工具通道（MEANPOOL） | 152 | 不经 JSON 生成 | 1.46870 |
| BASE03：预测器 → 冻结 Qwen 原始生成 | 152 | 91 | 5.92236 |

Q-Former 型连接器在这次三轮单种子运行中取得四种连接器最低的测试 MAE。常量前缀控制独立训练后的 MAE 为 1.96561；input MLP 和内部交叉注意力在本预算下均未优于该控制。

关闭连接器后，四种模型共享同一冻结文本模型输出：27/152 条满足严格 JSON，125 条保留为生成失败；完整样本 MAE 未定义。有效子集误差必须同时带出该分母。

BASE03 在全部 152 条样本上的原始预测器 MAE 为 1.46870；语言模型仅有 91 条有效答案，61 条格式失败，有效答案 MAE 为 5.92236，完整生成 MAE 未定义。原始输出出现对已为 pKD 的数值再次写出 -log10 运算；本阶段保留这些语义与格式失败，未修正文案或替换预测。

架构容量：内部交叉注意力在文本位置读取全部残基 KV；其余连接器将记忆压缩或表示为 16 个前缀向量。可训练参数分别为：input_mlp 282,752；qformer_style 350,848；internal_cross_attention 548,608；constant 24,576。这些比较同时包含读取位置、信息压缩方式和参数容量差异。

现有冻结预测器训练三十轮，连接器训练三轮；当前结果描述实际基础测试，架构优越性比较还需匹配训练预算与重复种子。数据库参考靶点、实验构建体/条件缺失和外部源覆盖限制继续沿用冻结数据合同。
