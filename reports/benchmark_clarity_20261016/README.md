# 先把基准说清楚

当前可比较的主任务是：给定肽、数据库参考靶蛋白及允许上下文，生成一个严格 JSON 的 pKD 数值。数据是既有实验测量的数据库记录；本轮测试计算预测误差及消息作用。实际测定构建物、pH、温度等信息尚缺，严格同条件肽对为0。

## 1. 哪些问题由哪个实验回答

| 问题 | 基准／对照 | 主要判读 |
|---|---|---|
| 能否预测既有测量？ | A1：新肽—已见参考靶标；新肽—新靶标家族，分别训练 | 原 pKD MAE、解析有效数、失败数；两个测试群体各自报告 |
| 接入深度是否带来收益？ | 同一固定消息、同一接收器，在 embedding 后／block14 后注入 | 同seed配对差值；参数、消息、查询数、额外位置均匹配 |
| 收益是否来自分子内容？ | 两个位置各训练相同参数的真实消息／TRAIN均值消息模型 | 真实与中性对照差值；关闭消息作为另一项推理干预 |
| 门控初始化是否改善优化？ | 固定 mid 位置，同一 tanh 门控，初值0／3 | 原主要指标；训练／验证损失、门控与残差范数作为机制诊断 |
| 短肽是否被全局池化稀释？ | 固定 mid 位置、K=16，8肽+8靶／拼接后全局16槽 | 相同参数与载荷下的系统差值；几何配额与实际注意力分开解释 |
| 表示里能否读出额外信息？ | 原 C2 条件探针，B与表示维数／拟合规则固定 | 规定摘要和函数族下的ΔMSE；与生成指标分表 |

两个场景共同test仅22条；known训练集有262条属于double测试集，known测试集有116条属于double训练集。这不是场景内划分泄漏，而是两个不同泛化问题的分配。每个场景独立初始化、独立训练和选点；训练过的发送器、接收器或归一化统计不跨场景传递。冻结的无标签预训练底座与数据无关初始化可以共享。不同场景MAE之差不能单独解释为难度效应。

`group_id`是DOI／序列家族的连通组件，用作相关性阻断和组bootstrap。它不是已核实的独立物理实验编号；独立实验数量保持未知。新报告采用“来源／家族连通组”，分组和已有区间均不改写。

## 3. 旧四法比较存在什么混杂

| 历史实现 | 可训练参数 | 实际通信 | LM位置 |
|---|---:|---|---|
| learned constant | 24,576 | 固定16个1536维软token | 额外16 |
| input MLP | 282,752 | 全部残基整体池化成16槽后映射 | 额外16 |
| learned-query 输入接口 | 350,848 | 16个query读取全部残基，输出16前缀 | 额外16 |
| 无门控单层内部注意力 | 548,608 | 每个文本位置直接读取全部N个残基 | 额外0 |

历史内部实现没有门控，`num_memory_tokens=16`没有约束其键数。历史配置中的“gated”名称与实际代码不一致，以本次追加说明纠正解释，旧配置和结果原字节保留。旧MLP整体池化时，测试肽的残基份额中位数约2%，纯肽槽中位数0；这是几何现象，尚非性能原因的因果证明。注意力模型实际肽权重此前没有记录。

前缀经过28层，内部在第14块后注入、经过后14层；梯度路径、压缩方式、参数和读取机会也同时改变。旧结果检验了这些具体系统，接入位置的归因需要新对照。

## 4. 保持哪些评价规则

- 旧samples、test_gold、划分、来源排除、底座、提示、标签序列化及严格解析器全部封存。
- 主要端点继续是全测试集pKD MAE与解析覆盖。任何生成失败都保留计数，full MAE仍为null；valid-only MAE按其条件分母报告。不补值、不裁剪、不人工修复。
- 全部训练3轮、batch4、1548更新；AdamW lr=3e-4、wd=.01、clip=1，24生成token，原验证全答案token NLL选最优、最早tie。不改成数值token损失选点。
- seeds固定17、42、2026；报告全部种子、同seed配对差、均值／样本SD。种子波动与固定模型的来源／家族组bootstrap分开，不能把重复seed当新增实验样本。
- C1完整答案NLL继续报告。格式／数值token分解、残差范数、注意力配额是新增机制诊断，不替代旧主指标。
- 旧测试已经观察过。本轮是同冻结基准上的预先规定后续检验；新模型选择仅用TRAIN／VALIDATION。更强确认需要另行独立外部评价，旧test不替换、不重划。

## 5. 什么才是本轮“同预算”

主比较采用固定发送器：每残基无仿射LayerNorm、8肽+8靶独立池化、同一固定Gaussian投影640→128、无仿射slot LayerNorm。投影seed314159，与数据和标签无关；发送器没有可训练参数。中性消息是该场景TRAIN真实消息的逐slot均值，所有对象固定16槽、mask全1。

两位置使用同构接收器：LN1536、1536→128、4头MHA128、128→1536、一个tanh标量门控，**464,001个可训练参数**。每次跨边界消息是16×128 float32，即8192字节；每个文本位置读同16个KV，写同维残差，额外LM位置都是0。相同seed的初始化tensor逐位相同。

这能清楚比较早期与中层读取。真正的16-token前缀仍有额外位置、不同query数和传播路径，应作为系统比较另列，不能称所有通信／计算轴完全匹配。即使本轮接收器操作匹配，梯度通过的冻结LM层数仍不同，实际FLOPs、时间和显存单独记录。

8192字节是约定模块边界的逻辑消息载荷，既不是实际网络／PCI搬运量，也不是Shannon信息量。训练时样本、token和读取次数匹配；生成时每次读取和24token上限匹配，但不同EOS可能导致实际调用数不同，真实流量另记。保留原解码停止规则，不用多余空调用凑总量。

接收器还会对padding及整批内已结束行计算再mask，故分别记录有效逻辑query、实际B×Lmax query、有效写入与实际张量字节。464,001是同构模块的可训练张量元素数，不等于可辨识统计自由度；标准attention的K-bias抵消、零门控首步分支梯度为0均如实记录。

本轮固定消息不含显式slot位置或肽／靶类型编码。8+8控制保留两种分子的池化配额，但注意力对KV槽置换近似不变，槽次序本身不能表达分子身份。原冻结prompt中的type0/1描述原样保留，新接口没有相应type IDs，存在语义缺口。两接入位置共享这一限制；池化扩展只能解释为两种池化系统的比较，不能声称已完成类型对齐或证明实际肽注意力增加。[独立实现审查](implementation_review.md)

## 6. 论文依据与实验次序

先执行主比较24项（2场景×3seed×2位置×真实／中性）；再固定mid位置检验门控初值6项；再固定mid及零门控检验池化配额6项。完整36项在新增结果打开前固定，不从中挑最佳seed／场景。扩展项与已完成主比较共享的同一配置结果明确复用，不重复计为独立模型。

固定配对差值为：early-real减mid-real、early-neutral减mid-neutral、各位置neutral减real、前两者的差中差；扩展为near-unit减zero、global16减balanced。正值对应命名处理的MAE降低。任一全样本MAE缺失时，该差值仍为null；3seed统计仅在3/3完整有效时给均值和SD，否则报告k/3及完整失败清单。不能只平均成功seed。

最终执行以本页和JSON的固定发送器36项为准。预算／文献审计中的可学习codec、真正prefix、无门控等是历史备选建议。本轮alpha=3仍是门控；early是动态残差注意力而非旧MLP或经典前缀。neutral只移除变化的消息内容，原允许prompt信息保留。

门控依据Flamingo的零初始化tanh残差；固定消息瓶颈依据Flamingo／BLIP-2；蛋白—文本任务表示学习动机来自ProtT3／ProtST。本轮改进是这些思想在当前pKD任务的受控迁移，原论文没有证明本任务的增益。训练集内表示预热列为后续独立方案，本轮先不叠加预热目标。
