# 内部连接器对照：论文证据、预算与可检验机制

本轮首先检验：在同一冻结 ESM2-150M、Qwen2.5-1.5B、A1 数据划分、允许上下文和输出协议下，内部接入是否比输入前缀稳定降低 pKD 误差，以及收益是否来自样本相关的分子消息。既有测试答案、划分、解析器、失败计数和旧结果继续冻结。本文是文献证据与后续预注册建议，未执行新训练。

## 先把比较对象说清楚

现有 `input_mlp`、`qformer_style`、`internal_cross_attention` 是本项目的最小连接器实现。检查 `scripts/foundation_20261016/connectors.py` 可见：普通 MLP 对肽与靶点拼接残基做全局自适应池化；Q-Former 风格用 16 个学习查询生成输入前缀；内部方法在第 14 个解码块后，将读取全部残基的跨注意力输出直接相加。内部方法目前没有输出门控。三者分别含 282,752、350,848、548,608 个可训练参数，常数消息含 24,576 个。当前结果比较这些具体系统；接入位置、压缩方式、接收器容量和通信读取机会同时变化。

已完成结果提供两条机制线索：常数消息同样明显降低答案 NLL；内部方法在两个留出场景的排名变化。前者要求排除格式先验，后者要求重复随机种子。当前结果不能单独确定失败来自优化、压缩或蛋白表示上限。[既有结果及统计范围](../foundation_results_20261016.md)

| 必须固定／记录的轴 | 可审计定义 |
|---|---|
| 数据与底座 | 冻结样本 ID、来源连通组、训练／验证／测试文件 SHA；相同 ESM 缓存、Qwen revision、上下文 allowlist、提示词、标签小数精度、解码和解析规则 |
| 活跃参数预算 | 分别计发送器、接收器、辅助头、门控和常数参数；只统计参与损失且能够更新的参数。增加未使用参数不能匹配容量；冻结／共享参数单列 |
| 一次消息载荷 | 在预先指定的模块边界，所有方法传相同 `K × d` 张量和 dtype；存储字节为 `K × d × 每元素字节`。这是载荷账本，不是 Shannon 信息量 |
| 源读取预算 | 同样的原始残基、type ID 和 mask；任何额外残基直连均计一次新通道。目标特征、标签、ID、来源字段的可见性保持一致 |
| 消息重用与计算 | 单列插层数、每层读取次数、受影响文本位置、生成步数及实际 FLOPs／时间。前缀经全部自注意力层传播，内部 KV 可在每个文本位置重读；相同 K 并不保证相同计算量 |
| 优化与选择 | 相同配对种子、训练样本顺序、梯度更新数、累计批量、优化器和验证选择预算；所有阶段与辅助损失均纳入预算。多阶段不能免费增加训练步数 |

最清楚的接入位置对照是：先冻结同一个发送器检查点，再比较匹配接收器预算的前缀与内部接收。若两端分别联合训练，应将结论写成“这两个受控系统的差异”，因为发送器也会学成不同的消息。参数预算与通信预算需要分别声明；一次运行很难同时精确匹配所有浮点运算，剩余差异应公开。

## 原论文证据卡

页码均为本地 PDF 从 1 开始的物理页。论文事实、迁移假设和待执行对照分开记录；机器可读版本含 PDF SHA、工作台 ID 和作者源码位置。[证据 JSON](literature_evidence.json)

### 1. Flamingo：固定瓶颈与身份保持的内部接入

**作者事实。** *Flamingo: a Visual Language Model for Few-Shot Learning*，Alayrac et al.，NeurIPS 2022，arXiv:2204.14198。PDF p5 §2.1–2.2/Fig.4 使用 Perceiver Resampler 将变长视觉特征变成 64 个 latent，并以零初始化的 `tanh(alpha)` 门控新增残差。p8 Table 3 分别消融门控、跨注意力结构、插层频率和 resampler；其中“只在中间接一次”与“每层接入”的参数和时耗也不同。原表提供机制动机，同时展示预算混杂。[官方论文](https://arxiv.org/abs/2204.14198) · [本地 PDF](../../docs/PUBLICATION_SCOPE.md)

**本课题假设。** 无门控随机残差可能在训练初期扰动冻结 Qwen 的隐藏分布；全残基单点注入也可能与固定瓶颈消息有不同的优化难度。验证需观察训练／验证 NLL、梯度、残差与隐藏状态范数比、门控轨迹和多种子误差。

**对应对照。** 在相同消息、参数与更新预算下比较门控零初始化、门控非零初始化、无门控；先固定一处插入。多层频率作为独立后续因子，并匹配总接收器参数和记录读取次数。冻结底座、视觉输入、原训练规模及数据混合均与本课题不同。

### 2. BLIP-2：查询瓶颈需要与训练目标配合

**作者事实。** Li et al.，ICML 2023。PDF p3 §3.1–3.2 的 Q-Former 用 32 个 768 维查询；第一阶段联合对比、匹配和 grounded generation 三种目标，第二阶段连接冻结 LLM。p6–7/Fig.5 对比移除表示学习阶段，报告零样本 VQA 下降。作者 LAVIS 源码 `blip2_qformer.py:268–274` 明确返回三个损失之和。[官方论文](https://proceedings.mlr.press/v202/li23q.html) · [作者源码](https://github.com/salesforce/LAVIS/blob/05cb670f47296522e24e7727e366b4a997d28582/lavis/models/blip2_models/blip2_qformer.py#L268) · [本地 PDF](../../docs/PUBLICATION_SCOPE.md)

**本课题假设。** 仅用约两千条 pKD 的短 JSON 答案训练随机连接器，可能优先学会答案格式与均值，而没有建立足够的任务表示。learned queries 本身不保证对齐。

**对应对照。** 同预算地比较直接生成训练与训练分区内的任务表示 warmup；额外阶段的步数、辅助头和标签使用都计账。pKD 回归辅助损失属于本课题迁移实现，原论文并未验证它。图像、BERT 初始化 Q-Former、三项原目标和大规模图文数据不能由当前最小模块等效替代。

### 3. ProtT3：蛋白领域的两阶段证据与数值任务边界

**作者事实。** Liu et al.，ACL 2024，DOI:10.18653/v1/2024.acl-long.324。PDF p2、p4–5 的第一阶段为蛋白—文本对比、匹配和 captioning；第二阶段将查询前缀交给 Galactica，并使用 LoRA。p6 Table 4 和 p16 Appendix C.2 提供无第一阶段与 MLP 对照。p14 Appendix B 专门指出数值输出和候选数影响难度，并讨论部分 QA 的数据偏差。作者仓库示例使用 ESM2-150M 和 8 queries。[官方论文](https://aclanthology.org/2024.acl-long.324/) · [作者源码](https://github.com/acharkq/ProtT3) · [本地 PDF](../../docs/PUBLICATION_SCOPE.md)

**本课题假设。** 可借鉴“先学习任务相关消息，再让 LLM 读消息”的阶段分工；同时应把数值预测、数值呈现和分子信息使用分开评价。当前冻结 Qwen 的最小查询模块称为 Q-Former 风格对照；完整 ProtT3 还包含不同底座、预训练目标与 LoRA。

**对应对照。** 保持底座双冻结，在同一 A1 train 上做辅助数值头的机制消融；验证集固定选正则和停止点。已下载 Swiss-Prot／ProteinKG25 保持隔离，外部预训练需要另外完成与冻结测试对象／家族／来源的暴露审计。

### 4. ProtST：对齐动机成立，冻结范围不同

**作者事实。** Xu et al.，ICML 2023。PDF p3–4 §3.2 使用单模态 mask、序列—文本 InfoNCE 对齐、多模态 mask；作者更新 PLM，冻结 biomedical LM。[官方论文](https://proceedings.mlr.press/v202/xu23t.html) · [本地 PDF](../../docs/PUBLICATION_SCOPE.md)

**本课题用途。** 支持将“任务表示学习”列为需要消融的因素。当前缓存固定且 PLM 冻结，完整 ProtST 的表示增强途径没有开放；不能从原文推出只更新连接器同样有效。将来换成已预训练 PLM 属于独立底座实验，本轮匹配对照继续使用原 ESM 缓存。

### 5. 条件探针：额外可读信息的基线要进入探针

**作者事实。** Hewitt et al.，EMNLP 2021，DOI:10.18653/v1/2021.emnlp-main.122。PDF p2 §2.3 比较 `[B;R]` 与 `[B;0]`；p3 §2.5–2.6 在指定函数族与对数损失下讨论条件 usable information。[官方论文](https://aclanthology.org/2021.emnlp-main.122/) · [本地 PDF](../../docs/PUBLICATION_SCOPE.md)

**本课题用途。** 当前回归探针的 ΔMSE 单位为 pKD²，衡量规定摘要／投影／线性族下的额外预测能力。后续固定 B、相同表示维数和训练预算，比较线性与小型 MLP 容量曲线；保留恒定／随机表示控制。正则和层选择仅用训练／验证。均值投影读不出信息与完整消息没有信息是不同命题。

### 6. 控制任务：探针容量与身份记忆需要分别测量

**作者事实。** Hewitt & Liang，EMNLP-IJCNLP 2019，DOI:10.18653/v1/D19-1275。PDF p1–3 将词类型随机标签作为控制，并比较真实性能与控制性能；p5 Table 1 展示相近真实任务性能可以伴随不同 selectivity。[官方论文](https://aclanthology.org/D19-1275/) · [本地 PDF](../../docs/PUBLICATION_SCOPE.md)

**本课题用途。** 用固定随机种子为分子身份分配一致的控制标签，报告所有容量档。严格家族留出下身份控制的可泛化性有限，解释时应报告实际身份覆盖。回归随机控制的误差差异按本课题定义另列；论文分类 selectivity 公式不直接套成 pKD 信息量。

### 7. ESM-2：表示可读性与当前任务能力分开

**作者事实。** Lin et al.，Science 2023，DOI:10.1126/science.ade2574；本地 PDF 是 2022-10-31 bioRxiv 版本，DOI:10.1101/2022.07.20.500902。本地 p3–4 §2 用接触与结构读出研究模型规模和表示。作者仓库同时区分 token-level、mean representation 和结构输出。[作者源码与正式引文](https://github.com/facebookresearch/esm) · [本地预印本](../../docs/PUBLICATION_SCOPE.md)

**本课题用途。** 先问同一缓存上的受控任务探针是否存在稳定增益，再追问连接器是否保留它。结构可读出性没有直接给出条件依赖 pKD 的保证；更换大 PLM 或 ESM 层需要新底座合同，不能作为本轮内部接入优势。

## 三项改进候选及预注册顺序

| 优先级／候选 | 机制与实施范围 | 必需对照 | 主终点与判读 |
|---|---|---|---|
| 1．共享固定瓶颈、分开肽／靶点配额 | 使用所有方法相同的 K、d、dtype 和活跃发送器预算；分开配额以检验长靶点挤占肽信息。Perceiver／Q-Former 提供固定 bottleneck 依据；类型平衡是本课题假设 | 固定同一发送器后比较 prefix／internal；全局配额与类型配额作为独立因子；共享输入证据与优化预算 | 冻结各场景的全样本生成有效率与原 pKD MAE；配对种子差、分组区间。类型效果先看训练／验证，测试按预注册一次报告 |
| 2．身份保持门控的内部注入 | 新分支使用 `h + tanh(alpha) × delta`，alpha=0；继续冻结 ESM/Qwen | alpha=0、非零初始化、无门控；训练步数／消息／接收器预算匹配；记录 gate 与梯度，不因测试成绩改初值 | 同一主终点；优化机制辅助终点为训练／验证 NLL、梯度有限性、残差范数比、门控轨迹和跨种子离散度 |
| 3．train-only 任务表示 warmup | 同一 A1 train 标签用共享小型回归辅助头学习消息，随后按既定 CE 训练；辅助头损失／标准化只使用 train | 直接 CE、warmup+CE、相同步数 CE；所有方法使用相同辅助头与预算。随机标签控制单列诊断 | 冻结主终点；额外观察消息在 B 外的 train/dev 可读出性以及任务数值 token NLL。它是两阶段思想的 pKD 迁移，不是原论文原损失复现 |

优先完成第一项预算清楚的多种子基线，再执行门控消融。第三项的确切损失、权重和阶段步数需在新增测试推理前冻结；可依据原理和训练／验证数据选择，不依据旧或新增测试集调节。三个候选应逐项检验，先把多个改动组合起来会失去解释能力。

## 机制诊断与评价不能混用

1. **格式先验与内容贡献。** 保留常数／关闭消息，并为不同位置实现匹配的常数消息。把既定答案中格式 token 与数值 token 的 teacher-forced NLL 分开报告，可定位 NLL 改善来自何处；这是本项目诊断，文献未证明当前格式效应。自由生成依然使用旧解码和解析规则，数值预测器的输出继续单列。
2. **表示的读出与模型的使用。** 条件探针回答额外可读出性；correct/off 答案 NLL 回答消息通道的作用。严格独立匹配 donor 仍为零，错配因果量保持未定义。常数消息有效不能被称为蛋白信息有效。
3. **随机性与抽样。** 配对使用预先冻结的多种子清单，逐种子呈现有效数、误差、耗时和失败；种子方差与测试来源连通组重采样分开报告。两场景分别给结论，旧单种子结果保持历史身份。
4. **选模型与读测试。** 运行前锁定比较清单、端点、种子、预算、停止与失败处理；训练／验证选择检查点。旧测试已经公开，当前验证属于该冻结基准上的受控后续检验。更强的外部泛化结论应另行建立未用于设计的新独立评价集，旧测试集继续保留。
