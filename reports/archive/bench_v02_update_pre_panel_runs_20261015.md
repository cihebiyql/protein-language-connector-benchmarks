# PepBridge Bench v0.2 更新与就绪状态

本轮已按分享对话最新三轮更新基准协议、机器配置、数据准备和评测合同。正式评价改为三类证据：A 实验预测，B 知识利用与迁移，C 信息干预与解释。旧18次实验保留为v0.1探索结果。当前已完成准备与检查，正式多任务训练尚未启动。

## 新版固定的评价

| 类别 | 面板 | 问题与主指标 |
|---|---|---|
| A 实验预测 | A1 亲和力 | PPIKB研究来源精确KD→pKD；MAE、靶点—条件内Spearman、真实肽对方向；Kliche/PEPBI锁定外部核验 |
| A 实验预测 | A2 保留时间 | PXD005573→PXD064311；分条件MAE/Spearman，32/128/512/2048目标标签预算曲线 |
| B 语言额外价值 | B1 未见功能 | ELM类别留出，所有方法使用相同去规则候选描述；类别宏平均MRR/Recall@1/3 |
| B 语言额外价值 | B2 证据组合 | 分子事实＋允许背景，留出关系—问题组合；联合正确率、事实覆盖及错误推断 |
| C 信息传递 | C1 内容干预 | 正确、关闭、同靶点/条件/状态匹配错配、单独训练恒定消息、真实配对交换 |
| C 信息传递 | C2 可用性与解释 | 等容量的ESM/连接器/答案前状态探针、选择性干预、局部实验或结构证据 |

C3原子事实文字核验独立出表：支持精确率、必要事实覆盖、矛盾和未支持推断。200个独立案例是目标，需两位盲法评审与分歧仲裁。成本和跨底座适配另外报告，不计算混合任务总分。

## 对原基准的实质调整

1. Benz降为基础对齐及辅助已知阳性检索；亲和力与RT承担真实数值终点。
2. 未见靶点必须有真实可用序列。参考全长序列与实际实验构建体分别标注，不能再用陌生opaque编号承担新靶点泛化。
3. 生成通道保留真实输出文本、解析失败和有效率；答案前隐藏状态读出头单独报告。旧alias logits不转称生成成绩。
4. 正式主结果每个seed使用一个多任务源连接器checkpoint。各任务独立选最好checkpoint后拼分被拒绝；少样本适配版本保留共同源checkpoint身份。
5. BASE-00..06增加残基注意力预测器、序列—文本判别器、完整结构化预测→同一LLM、Q-Former及普通内部跨注意力。差分、靶点、条件和背景信息对所有合理基线保持一致。公开原系统另表。
6. M0为旧MLP接口；M1侧记忆、M2分层问题读取、M3差异通道、M4配对一致性作为消融设计登记，尚未实现新模型训练。同构M1和BASE-06共用一次结果，避免重命名重复计数。
7. phase 0先锁外部实验与ELM类别，再做跨源/家族划分。历史使用过Kliche训练样本的权重不能转称新版整源零暴露模型。

## 实现与检查

[机器配置](../../historical/configs/bench_v02.json)注册面板、指标、基线、候选消融、训练阶段、通道和历史迁移。`scripts/bench_v02/`新增三源准备器、无标签输入视图、回归/排序/配对/原子事实及干预算子、同靶点状态匹配供体、运行合同、评分和就绪检查。

A1/A2的`model_inputs`与pKD、RT、原始Affinity列、RT标准差/检测次数、来源DOI分开导出；B1使用独立匿名候选目录。689条A1候选靶点超过ESM通常的1022残基输入长度，后续需要对所有方法采用相同分块规则，不静默截断后冒充完整构建体。

正式评分要求实际checkpoint文件及指纹、物理协议/金标准/候选映射锁、非空合格测试对象和统一源checkpoint。未知靶点序列、非KD回归标签、答案后探针、候选注入、空答案及格式失败不会成为完美成绩。无效生成只报告有效子集的条件指标，并禁止进入正式主表。

当前[就绪报告](../../results/legacy/bench_v02/readiness.json)准确标记各面板的待完成条件，`scores=null`。现有18次运行对应的21个关键结果/权重指纹验证未改变。指标单元测试使用手算fixture，不作为新版实验成绩。

新增69项测试通过；连同原77项回归检查，共146项通过。独立复核覆盖空金标准、错误终点、缺checkpoint、未锁候选映射、未知化学状态供体及正式接口指纹检查，修复后无阻断性代码问题。正式训练待完成项属于数据和证据准备状态。

## 离线复验入口

在工作目录使用既有Windows Python环境：

```powershell
python scripts/bench_v02/prepare_affinity.py
python scripts/bench_v02/prepare_rt.py
python scripts/bench_v02/prepare_elm.py --scope model_eukaryotes --out data/processed/bench_v02/b1_model_eukaryotes
python scripts/bench_v02/build_inputs.py
python scripts/bench_v02/audit.py
python -m unittest discover -s tests -p "test_v02*.py"
```

`python scripts/bench_v02/audit.py --panel A1 --require-ready`当前应以非零码拒绝正式训练，原因是外部来源和双侧划分未锁。该退出是数据检查，不是权限确认。正式模型输出可用`evaluate.py --help`查看所需真实文本、通道、checkpoint、协议与金标准锁字段；当前尚无合法冻结锁文件。

详细规则见[v0.2协议](../bench_v02_protocol.md)，迁移见[历史结果迁移说明](../bench_v02_migration.md)。来源和逐行排除分别见[A1](../bench_v02_affinity.md)、[A2](../bench_v02_rt.md)、[ELM](../bench_v02_elm.md)。
