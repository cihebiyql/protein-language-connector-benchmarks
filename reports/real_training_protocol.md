# L30-J0 / L15-J14 真实数据训练与干预协议

日期：2026-10-15，Asia/Shanghai。本文件记录正式桥训练的预定规则及原始来源核验后的数据修订。T1吞吐计时与T3输入覆盖、序列身份和标签证据的修订见对应段落；各次运行配置、逐轮轨迹、样本级预测和真实测量来源共同组成审计记录。

## 本轮问题与比较对象

本轮检验两种冻结 ESM2-150M → 冻结 Qwen2.5-1.5B-Instruct 接口能否在相同数据和优化预算下优于 ESM2＋MLP，并检验预测是否依赖当前肽的消息。

| 方法 | ESM 读取 | Qwen 写入 | 可训练部分 |
|---|---|---|---|
| ESM2＋MLP | 第30层残基均值 | 无 | 640→256→34 MLP |
| L30-J0 | 第30层逐残基状态 | 输入嵌入 | 既有 ResidueBridge |
| L15-J14 | 第15层逐残基状态 | 第14个 block 后 | 同构 ResidueBridge |

基础模型参数全冻结。接口训练期间，写入后 Qwen 的计算图保留以传回梯度。可训练分类头不替代 Qwen 的语言模型输出层。比较 L30-J0 和 L15-J14 同时改变了读取层和写入层，结论对应两种联合配置；隔离内部写入的贡献需要后续补齐 L30-J14 / L15-J0。

## 阶段 A 的预算与选点

训练 seeds 固定为17、42、2026，三种方法均完整运行三个种子。所有方法使用同一逐 epoch 样本排列：epoch从1起，使用 `torch.randperm(n, generator=torch.Generator().manual_seed(seed + epoch))` 在CPU生成；排列独立于模型初始化、dropout 和 CUDA RNG 消耗。模型初始化和 stochastic modules 使用对应训练 seed。记录实际排列哈希。

| 项目 | 固定规则 |
|---|---|
| epoch 上限 | 30，完整运行，不用早停缩短某一方法 |
| 有效 batch | 64条生物样本；末 batch 为58条 |
| optimizer steps | 每 epoch 30步，总900步 |
| 优化器 | AdamW，lr=3e-4，betas=(0.9,0.999)，eps=1e-8，weight_decay=0.01 |
| 学习率日程 | 恒定；无基于测试集调整 |
| 标签权重 | 每条样本总权重1；在其已记录阳性上均分概率质量 |
| MLP损失 | 34候选 softmax 交叉熵 |
| 桥损失 | answer-only的Qwen完整词表交叉熵；阳性对应固定单token别名 |
| checkpoint | 每 epoch 评估固定验证集；MRR最高者，严格相同时选择最早 epoch |
| 测试时点 | 训练完成并选择 checkpoint 后统一评估 |

T1正式桥训练的微 batch 固定8、常规累积8次，保持有效batch64。L30-J0 seed17的microbatch2前4轮只用于吞吐计时，保存在 `timing_micro2_L30-J0_seed17`；正式三种子均从头训练，不将计时结果加入最终比较。微batch调整由吞吐计时确定。梯度累积先累加样本损失之和，再除以该有效 batch 的实际样本数；末尾58条保持每样本等权。每种方法每个seed记录训练样本呈现数57,420、实际 optimizer steps、微 batch、有效 batch、耗时、CUDA allocated/reserved 峰值、可训练参数量与冻结参数检查。

相同预算在此指样本和优化步预算。三种方法的可训练参数量、逐残基/均值输入和计算成本不同；桥的完整词表损失还包含把概率质量分配至候选token的约束，MLP使用候选内条件化损失。同时报告这些差异。旧 `b1_pilot.json` 的27轮早停结果作为历史结果保留，公平主表使用本轮重新训练的 MLP。

## 语言模型评分接口

桥模型使用冻结 Qwen 下一 token 的34个固定候选别名 logits 排名。别名须在所用 tokenizer 中各为单个 token、token ID 互异；候选目录、映射、prompt、分子 slot、答案位置和实际长度保存到运行产物。候选映射在训练前固定，所有桥模型和干预条件完全相同。

这是一项固定34候选的受限排序测试。它保留 Qwen 语言模型输出层和全部后续计算，降低了逐候选生成开销；固定别名提供的是任务内可学习标签接口。自然靶点名称的开放生成、JSON合法性、解释事实质量、候选外迁移和语言知识组合属于独立能力，需由相应实验评价。

主指标使用34候选 logits；减去全词表或候选集共同的 log-normalizer 不改变同一样本的排名。完整词表训练损失额外约束候选外token概率，因此两种归一化的训练目标存在差异。评估可只计算冻结lm_head的对应34行以降低显存/计算，并验证其值与完整输出层的对应logits一致。

## T1 与统计口径

每条样本的 Known-positive Recall@3 为 Top3 命中阳性数 / 已记录阳性数，MRR 为第一个已记录阳性的倒数排名。稳定并列按固定候选顺序打破。报告样本平均、分母和完整34项排名。未记录关系仍为未知；softmax目标会压低其相对分数，因此该目标对应已知阳性排序。

主比较为 L30-J0−MLP、L15-J14−MLP、L15-J14−L30-J0 的同样本差值。使用测试集 group_id 进行配对 cluster bootstrap：固定seed2026，2,000次；每次有放回抽235个组，纳入所抽组的全部样本，重复抽中组保留重复权重；按合并样本的等样本权重重算差值，取2.5/97.5百分位。所有模型和干预共享同一组重采样。逐seed报告结果与差值；另报告三seed均值、标准差，以及先对同样本的三seed指标取均值后进行的组bootstrap。该区间刻画固定三个已训练模型下的测试组采样不确定性，训练波动由seed间标准差描述。

## T2：冻结 checkpoint 后的真实消息干预

T2 复用全部387条 T1 测试序列，不创建训练集、不重新选点。prompt、候选目录、slot、attention mask 和 checkpoint 保持固定。

| 条件 | 实际操作 |
|---|---|
| 正确消息 | 当前样本真实 ESM 表示经已训练桥得到消息 |
| 关闭消息 | 将完整消息置零，slot及其原始 token 保留 |
| 错配消息 | 替换为另一个真实测试样本的 ESM 表示，经同一桥生成消息 |

每个受体的供体必须来自同一固定 test split、sample_id和group_id不同、长度差≤2 aa，且已记录 targets 集合无交集。使用固定seed42与受体/供体 ID 的稳定 SHA-256 排序，取前10个互异供体；供体映射在查看模型输出前保存，所有桥模型和训练seed复用 `mlp_donors.json` 中的同一映射。允许同一供体被不同受体使用。测试标签只用于预先定义干预配对，不用于训练或checkpoint选择。

实际数据每个受体有319–386个合格供体，全部可取满10个。实现仍须记录不足时的合格数与实际数，禁止有放回凑满。无交集指已记录标签条件，符合条件的分子仍可能共享未测相互作用。

逐受体先计算10个供体预测的指标平均，再计算387个受体平均和组级区间；3,870次错配不作为3,870个独立样本。保存每个供体的排名及受体级聚合。报告正确−关闭的实际使用收益和正确−错配的配对信息收益。另报Top1/Top3变化率及供体已记录标签的排名变化，以区分信息使用和单纯扰动敏感性。错配下降需结合正确优于关闭共同解释。

## T3：真实配对训练与测量测试

阶段 B 使用 Kliche D2 中可定位具体 WT/变体关系、双端输入库覆盖均大于零的真实序列对。每对保留原始 sheet/row、relationship_id/relates_to、靶点构建体、两条实际序列、丰度证据和方向来源。D2标签为实测screen-count方向的弱监督：EV3单端p值的比较对象没有公开索引，因此不将该p值称为恢复的作者单肽配对显著性。EV6汇总组标签不直接复制给全部重叠肽；no_effect不作为等效标签。最终保留59对，34 train / 16 val / 9 test；原划分分配在输入覆盖QC排除6对后保留。

D2在排除 G1/EV8 对应家族和区段后按母体/变体系列、同序列/高相似性连通组固定训练/验证/测试。跨源 Benz关系须逐对标注，真实肽对不得因模型预测困难而排除。同一生物肽对呈现 A/B 和 B/A 时同步交换标签，训练呈现数和独立对数分别记录，两个方向永远属于同一 split。

阶段 B 从相应阶段 A checkpoint初始化，三个种子仍为17/42/2026。每epoch按CPU `Generator(seed+epoch)` 打乱34个D2训练对，以32和2分两批；每批加入同样数量D1训练回放，损失按两任务的实际样本总数平均。D1使用CPU `Generator(seed+100000+epoch)` 的训练集排列，取前34条，epoch内无放回。A/B训练翻转由 `SHA256(seed|epoch|pair_id)` 首字节模2确定，同步交换消息和标签；验证/测试保留原序。固定30个epoch、60步、每epoch34对+34条D1，总2,040次样本呈现。桥微batch2，均分累积保持32+32及尾部2+2；两种桥配置一致。只按D2验证集方向balanced accuracy选checkpoint，同分选最早。MLP使用同一D2划分、seed、呈现顺序、翻转、回放和60步预算。

T3固定目录包含全部D2与全部29行G1输入中出现的测量对象身份；KEAP名称按构建体规范化，KPNA4 major/minor口袋分开。两个方法使用同一34项opaque `D000`等编号：桥prompt仅见opaque编号，MLP使用相应onehot；raw gene、domain和KD不进入模型。数值预处理只用T1训练统计量，目录本身不拟合标签。

D2验证13/16、测试4/9在T1 train存在同母体或近序列暴露，保持原T1划分并附5对/4组洁净D2测试子集。G1主方向面板17行/12母体/13系列均无该训练暴露；其中ABRAXAS1两口袋和BCL11A–CLTC共3行存在Table1/EV8与附录S5序列冲突，主面板按Table1+EV8优先保留，另附来源一致14行敏感性子集。各个子集独立报告分母和group_id重采样区间。

T3主结果包含D2 grouped held-out的方向balanced accuracy、准确率、两方向混淆矩阵和A/B交换一致率。T2在D2和G1肽对上评估正确、关闭和A/B消息交换；交换只改分子状态及其mask，标签、靶点和文本位置不动。将交换预测按原始标签评分，并另按互补标签报告反转准确率及预测反转率。供体错配仅从当前测试面板同split、同测量靶点、异group、异记录方向、双端长度各差≤2的真实肽对中取至多10个互异供体，seed42稳定排序；不足或0个供体逐样本记录，供体对照汇总只在有覆盖的受体上进行。全部样本仍参加关闭和交换对照。组级bootstrap固定2,000次、seed2026；balanced accuracy区间排除丢失原面板已有类别的抽样并报告有效抽样数。

G1外部定量核验使用真实、可映射的同靶点/同口袋/可比条件肽对。精确KD相差≥2倍时按KD较小者结合更强；界限记录仅在最保守范围仍能支持至少2倍时计入方向；小于2倍、n.d.和方向不明单列，n.b.保留作者定义与测试上限后判断。保留筛选与测量冲突记录。分别报告正确数/可判方向数、小变化数、歧义数、独立变体系列数；不得预设分母24。CDC45–KPNA7的参考KD为6.6±0.7 μM，对应变体380±15 μM。

T1 checkpoint直接按靶点分数比较两肽时，结果标为T1→T3零样本排序迁移；对未在34候选中的靶点标明覆盖不足。阶段B配对训练结果独立报告。PEPBI在取得并严格匹配实验记录后作为外部扩展，本轮缺失状态单列。
