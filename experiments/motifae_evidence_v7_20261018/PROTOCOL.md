# MotifAE 逐残基证据接口：独立探索试验

接入顺序是 `ESM2-650M H33 → 冻结 MotifAE k3 → TRAIN学习并独立资格验证的特征关联 → 带位置的证据卡 → 冻结 Qwen3-4B-Instruct-2507`。本轮不训练Qwen，不改变正在运行的v6或其停止条件。

作者的末层表示已经包含ESM自身LayerNorm，保持其原始尺度，不补零、不复用150M池化缓存、不做额外L2单位化。首先用作者提供的719残基参考表示核对提取数值，验证权重指纹、重建误差、稀疏性和残基覆盖。代码固定提交为 `8dd6a7588d30726fef98c789dac3042370e829c5`，权重固定Zenodo20547228的k3；特征编号不与其他检查点混用。

数据仅从旧ELM TRAIN派生。先按父蛋白、同源组、局部序列家族及共同来源PMID作传递分组，再固定哈希划分。排除超过1022残基的完整父蛋白后，得到307个位点、262条完整父蛋白：新TRAIN201、资格集39、探索测试67。旧validation134和TEST76完全保留且不参与本轮。短肽左右使用由样本哈希预定的4–12残基侧翼，范围随样本变化；同一短肽和父蛋白始终同分区。

特征只能用新TRAIN选择和命名。每类选一个最匹配特征，至少2个TRAIN父蛋白；以资格集至少2个父蛋白、平均定位AUROC≥0.70作为可命名关联的条件。阈值取TRAIN未标注参考位置的95%分位数。资格不通过的保留为未知。固定规则可能导致较低覆盖，全部67个探索测试位点保留，不改变分区以补足某类样本。未在TRAIN出现的HCF类别也保留，不凭空建立词典。

对照包括同一650M原始H33的TRAIN监督线性探针、原始正则匹配、原始短肽序列和确定性证据模板。这样分别检查650M底座变化、稀疏特征变化和语言组织的贡献。编码完整父蛋白与重新编码独立短序列的结果分开统计，不能把父蛋白语境中的关联直接当成孤立肽已经具备相同实验功能。

Qwen始终使用同一冻结4B模型和同一提示规则，根据不同问题回答基序类别、位置、孤立肽实验活性是否已获证明、以及所引用的证据记录。证据卡只使用短序列的预测特征和冻结词典，不读取该样本测试注释。加入固定种子错配证据卡对照。报告真实生成的JSON有效率、已知阳性类别恢复、位置重合、证据引用及超出证据的活性断言，不让Qwen给自身回答评分。确定性模板用于检验Qwen是否只重述已给事实。

探索信号在测试前固定为四项同时满足：相同锚点、按父蛋白配对的短肽定位AUROC相比原始H33探针平均增加至少0.02；MotifAE卡的Qwen已知阳性类别恢复率超过序列、正则卡及H33探针卡中的最好者至少2个百分点；换错卡后该恢复率下降至少2个百分点；活性过度断言不超过其他Qwen方案中的最低值。满足只记为值得进一步验证的探索信号，不代替统计显著性、多种子训练或原v6的继续/暂停规则。完整实验未满足则报告未见预设额外增益；技术未完成单独记录，不作科学否定。

这是已标注父蛋白区域向短序列的注释迁移试验；未标注位置用于定位参照，不视为实验阴性。类别、定位与证据边界问题不等于三种独立生物学功能。词典覆盖、特征效用和语言证据忠实度分别报告。仅凭文字流畅或引用格式正确不能认定原内部连接器方向已成功。

本轮固定使用node1第四张项目GPU4，与v6的3、5、6合计不超过4张；各阶段顺序运行，释放ESM/MotifAE后才加载Qwen。CPU阶段2线程，不安装新依赖，不修改共享环境，不创建定时监控。原始ELM数据、位置、特征、逐条证据卡和回答保留私有；GitHub发布代码、协议、聚合指标和指纹。
