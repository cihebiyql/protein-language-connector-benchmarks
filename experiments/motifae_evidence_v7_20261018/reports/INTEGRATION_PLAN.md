# 接入方案与后续分界

当前执行证据卡路线：ESM650M和MotifAE均冻结，逐残基保留位置；关联词典只用TRAIN选择特征和名称，再由资格集决定是否可用。Qwen读取预测证据回答类别、位置、证据来源与推断边界。没有合格名称的特征以未知编号保存。

先分别检查三层：提取是否忠于作者数值；特征在独立短序列上是否保留已知区域关联；Qwen是否正确使用证据。特征定位的增益、可命名覆盖率和Qwen语言表现分开报告。定位参照的未标注位置不是实验阴性；短序列没有继承父蛋白已经测过的孤立肽活性。

若显示额外信号，后续数值接入应另建实验：在同一650M骨干、同一数据划分下，对比原始H33、MotifAE重建H33和稀疏特征token，使用相同连接器参数与信息槽预算。重建H33仍为1280维，可以先获得最直接的维度匹配对照。稀疏token可用冻结decoder列表示特征身份，再结合激活和位置，避免假定Qwen自然理解任意feature编号。

数值路线需要独立训练与消融，当前没有执行，也不向v6追加新方案。只有Qwen重述证据卡、格式正确，或更换为650M后单独提高分数，都不足以证明内部知识迁移。模板和原始H33对照用于区分这些来源。

若完整探索测试没有额外收益，保留结果并报告命名覆盖、上下文依赖或回答忠实度具体卡在哪一层。单个小探索面板不承担跨随机种子稳定收益的结论；原v6仍按其已冻结的九组结果作独立继续/暂停判断。
