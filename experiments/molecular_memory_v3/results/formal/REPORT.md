# V3 远端结果独立审计

本轮36项登记实验中，**32项完成训练、完整预测并通过canonical验收，4项训练中断**。现有结果支持“新框架已能稳定执行和生成合法输出”，尚不支持“完整新架构在两个场景具有稳定精度优势”。本审计仅运行标准库文件读取、实际SHA256、原canonical校验器和逐行评分，没有模型加载、forward、训练、GPU操作或过期任务恢复。2026-10-16的旧30项已验收实验不计入本轮。

审计在node1原执行路径读取原合同、原supervisor receipt、archive receipt、result-record与terminal validation，重新调用未改动的canonical `validate(..., check_files=True)`。32项当前均为valid=true、valid_for_acceptance=true、files_skipped=[]。同时对archive receipt的合同／result-record／validation摘要、进程退出0及清理收据进行交叉核对。随后用冻结原评分程序重新核对checkpoint、完整validation历史和最小NLL选点，以及LM、numeric、C1全部逐行记录；32项重算的完整JSON与原`case/result.json`逐值相等。

实际哈希11,447,364,273字节。相同文件的重复hash仅在(path,mtime_ns,size,inode,device)完全相同时复用；每个首次hash前后及整个审计结束均核对stat稳定。校验器源文件、原合同及原收据均未修改。第一次独立fit计数读取中的路径类型错误已修正，并重新读取全部fit manifest、实际预算和history；不影响前述canonical和逐行评分。

另写独立标准库公式，从原始冻结gold和原逐行预测交叉计算全部32项的LM/numeric MAE、RMSE、平均秩Spearman、靶点宏平均，以及C1的NLL和数值误差差，共320个标量核验。该公式实现不调用原evaluator的指标函数；全数在相对／绝对1e-12算术容差内通过，最大绝对差3.553e-15。容差仅用于重构核验，不用于改变优势方向或选择checkpoint。

完整的已知靶点M2−M0配对改善为0.074171±0.229078，只有2/3 seed改善；M1−M0为0.010175±0.228984，只有1/3改善。均不足以称为稳定逐步提升。

## C1解释边界

32项同一checkpoint的branch-off诊断均完成。G_off均为正，范围0.644142—0.678776 nats/answer-token；数值通道off−on MAE为27项正、5项负。这证明训练后的支路会影响当前模型，但“使用支路”和“比容量匹配的其他模型泛化更好”是不同结论。C1不能代替上面的完整TEST精度比较。

TRAIN-mean干预未执行。独立生物donor和可靠同条件pair均为0，P/H保持未定义。没有把固定θ计算敏感性称作生物因果或互信息；没有新增事实／解释／配对金标准。正式评价标准、固定划分、失败分母及已有结果均未调整。

本轮下一步应先修复监控竞态，在新合同及新输出目录中登记补齐缺失seed；架构继续改进需要TRAIN／validation诊断和独立协议，不能以此次TEST反馈修改当前已冻结评价。
