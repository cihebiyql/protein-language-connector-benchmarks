# 三任务连接器真实训练对照

热稳定性、功能描述检索和保留时间已接入冻结ESM2-150M与冻结Qwen之间的记忆读取架构。本轮独立训练45组模型，不改原pKD划分、源代码、评价或已有结果。正式队列已在node1启动；最新完成状态见 `COMPLETION_STATUS.json`，完整终态结果由本次任务关联的完成进程取回、独立复核并同步GitHub。

每任务每种子包含：一个共享ESM基线、1.5B上的M0/M3、4B上的M0/M3。三个任务、三个种子17／42／2026，共45个全新fit。两个Qwen分别为固定revision的Qwen2.5-1.5B-Instruct和Qwen3-4B-Instruct-2507。

## 单分子任务的架构适配

本轮三个任务均为单序列输入。两臂同时移除靶点和跨分子关系模块，只保留分子P和条件C，不填伪靶蛋白：

|方法|分子表示与读取|任务输出|
|---|---|---|
|ESM基线|同一冻结H15/H30缓存、相同条件，FP32任务MLP；不在线运行Qwen|标量回归或语义候选排序|
|M0|两套独立H30投影，固定非零anchor控制路由，内部注意力读取|答案前读出与独立语言生成|
|M3|H15/H30投影，以问题的答案前状态控制路由，内部注意力读取|答案前读出与独立语言生成|

M0与M3均为两个8槽分子视图和10槽条件，共26×128×float32＝13,312逻辑字节。1.5B在第14个decoder块后写入，4B在第18块后写入。ESM和Qwen冻结，连接器、条件嵌入及任务头训练；冻结LM的计算仍保留向连接器的梯度路径。

|任务头|ESM基线参数|1.5B M0／M3参数|4B M0／M3参数|
|---|---:|---:|---:|
|热稳定性／保留时间|2,000,385|1,222,278|1,488,518|
|功能描述排序|2,213,504|1,614,213|2,010,501|

M0/M3在同一任务、同一底座内参数和通信匹配；ESM基线及跨底座的参数和FLOPs分别报告。这轮单分子对照检验来源层和问题路由的组合，跨分子关系模块仍由原双分子任务检验。

各任务使用固定任务问题、分别训练；M3的问题路由在任务内可能基本恒定。此轮不单独估计随问题变化的路由收益，也不把三个独立模型的结果当成跨任务迁移。

ELM不使用固定类别ID分类头。所有方法、两个底座共享同一组冻结Qwen2.5描述向量，训练语义匹配头对固定31条文字描述排序。ESM基线仅使用离线描述向量，无在线语言模型推理；正例软目标用于相对排序，不将未知关系解释为实验阴性。

## 正式训练预算

根据实际TRAIN-only资格测试的耗时与显存，在查看新正式验证／测试分数之前，将首轮统一冻结为3个完整epoch，micro1×累积4＝有效批量4，AdamW学习率3e-4、weight decay0.01、梯度裁剪1。

|任务|每组更新数|每组正式训练样本呈现|
|---|---:|---:|
|热稳定性|5466|21861|
|功能描述|285|1134|
|保留时间|3714|14856|

每个case先用独立进程完成4次更新、16条TRAIN样本和8条TRAIN生成资格检查，再从全新进程、重新设定种子与初态进行正式fit。资格权重、优化器和随机状态不继承，额外资格计算单列，不混入正式训练更新数。资格检查使用技术指标，不按准确率筛选。

回归使用TRAIN-only标准化读出MSE；连接器另加答案token交叉熵。ELM使用已知正例语义排名损失，连接器另加正例描述JSON交叉熵。各任务独立拟合和选点，不跨任务继承接口权重或统计；本轮不宣称统一多任务模型或跨任务迁移。

选择规则为完整Meltome验证Spearman最大、完整ELM验证类别宏MRR最大、RT525条选择集MAE最小，完全同分取最早epoch。保存检查点及测试前冻结记录后才读取测试集；固定后才计算RT校准区间。全部种子按计划执行，早期无优势不会触发挑种子或改评价。

## 两条输出与输入依赖检查

读出通道和语言通道分开评分。语言输出严格为单字段JSON：`melting_temperature_c`、`retention_time_min`或`function`。回归最多24个新token，功能描述最多256个，greedy，生成batch8。保留完整测试分母、格式失败、非有限和缺失输出；数值读出不修补生成结果。

ELM语言端点为生成描述对固定候选文字的严格命中，语义排名端点使用完整31候选。严格描述命中不等于自由文本功能质量。各连接器检查点另做同权重记忆on/off读出C1，解释为分支依赖。

## 实际资格测试与因果检查修复

完整缓存已核验17,279条独立序列及6,325,974个残基。ESM在最多1022残基分块后保持原顺序拼接、取第15块及最终归一化30层，再池化成8槽；无跨块注意力，池化有损。最长34,350残基序列保留全覆盖。缓存使用固定权重、Transformers4.51.3、FP32、eager、禁用TF32及确定性数值策略。

初次连接器资格测试完成了真实更新，但旧开发检查将长度T与T+2的BF16结果比较而误报因果失败。真实GPU诊断证明：同形状只改未来内容时，读出、隐藏状态、路由逐位相同；改变前缀的正控能检出变化；即使关闭连接器也会出现旧长度变化差异。新检查改用同形状未来内容替换，严格1e-5阈值保持不变，并同时核对读出、隐藏状态和路由。原失败、检查点与旧生产源码均保留在私有档案。

新一轮代表性6项TRAIN资格测试全部通过：三个任务各一个ESM基线与1.5B M3，均4更新／16样本，未打开验证、校准或测试。正式队列中的M0及4B等各case仍先独立通过同一技术资格，再开始新fit。不能将这些资格结果计为正式完成或稳定提升。
