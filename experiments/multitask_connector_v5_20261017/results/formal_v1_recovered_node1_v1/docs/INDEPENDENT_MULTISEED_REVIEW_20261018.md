# 三任务连接器多随机种子结果

本轮固定基准中，M3相对同底座M0没有稳定提升。ESM在三个主指标的种子均值均为最好；M3相对ESM的18次配对全部落后。

覆盖45个固定实验位置：三个任务、三个种子17/42/2026，ESM以及两个Qwen底座上的M0/M3。所有种子和原始坏结果完整保留；显存失败的功能描述4B-M3 seed17以同合同的新尝试恢复，旧失败记录保留。

六个任务与底座组合均未呈现三个种子全部有利于M3。M3/M0的18次配对合计5胜13负；这些是共享固定测试集上的训练重复，不能当作18个独立生物学数据集。

热稳定性1.5B的M3均值增加0.00379，但只赢一个种子；seed42下M0为−0.02912、M3为0.01419，两个方法在该种子都明显退化。另两个种子M3均低于M0。

功能检索4B的M3为2胜1负，但平均增益仅0.00000888；该微小均值差未形成三种子一致优势。保留时间两个底座的M3均为0胜3负，平均MAE分别比M0高0.76864和0.97473分钟。

4B在回归任务上减少了1.5B所见的大幅种子波动，完整M3仍未超过简单M0或ESM。当前应优先保留ESM和M0作为对照，定位seed42退化及功能描述生成问题，再逐项验证修改。

## 语言生成与C1

功能描述主MRR来自31候选的排序头。12个连接器运行、共912条生成结果的规范阳性描述匹配数为0；JSON能解析或描述属于目录，都不等于命中该样本的阳性功能。这个严格目录命中指标也不等于自由文本语义真伪评价。

热稳定性的语言通道有9/12个运行全量完整，另外3个共50条无效输出；保留时间有10/12个运行全量完整，另外2个共15条无效输出。按冻结规则，这些不完整运行的总体语言MAE、RMSE和Spearman保持null，不能删除无效行再重新汇总。

C1开关比较显示多数回归运行使用了连接分支，但分支被使用与M3优于M0是两个不同问题；本轮配对结果仍未显示M3新增机制的稳定收益。
